# 全参考模式重写输出格式指南

本指南说明全参考模式下重写输出的组织方式和编写方法。

用中文撰写全部六个重写部分。仅对 `<d>` 内的对白和歌词、以及场景中可见的文字保留原文语言。

**描述详细度**：`detailed_description` 应尽可能详细、明确。对每个镜头，清晰确立当前构图、主体外观与位置、环境与光照、动作与状态变化、镜头运动、当前声音，以及参考内容实际出现或生效的节点。避免将描述缩减为情节梗概或参考关系列表。

> 镜头、镜头运动、说话者、对白和普通声音的基本格式与视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）共享。本指南聚焦于全参考模式特有的参考标签、分析部分和格式差异。

## 1. 整体结构

一个完整的重写输出由以下六个部分组成，顺序如下：

| 部分 | 用途 |
| --- | --- |
| `subject_definitions` | 定义参考内容及其参考标签 |
| `summary` | 概述任务类型、目标视频和主要参考关系 |
| `retention_analysis` | 描述参考内容如何被保留、迁移或复用 |
| `detailed_description` | 按播放顺序描述画面、动作、镜头、声音和对白 |
| `overall_soundscape` | 概括环境声和物理声音 |
| `non_diegetic_music` | 描述仅观众可听到的背景音乐 |

## 2. 参考标签与定义（`subject_definitions`）

全参考重写使用四种类型的标签来标识参考内容的来源和角色：

| 标签 | 含义 |
| --- | --- |
| `<Subject N>` | 从参考素材中抽象出的、可在目标视频中复用或修改的可见内容 |
| `<Picture N>` | 用作具体目标帧或镜头规划锚点的参考图像 |
| `<Video N>` | 提供编辑源、续接起点或整段视频时间结构的参考视频 |
| `<Audio N>` | 被复制或参考的音频信号 |

> 一旦某个参考标签被分配给一段内容，它在 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 和音频部分中保持相同含义。

`subject_definitions` 定义后续需要单独追踪的每段参考内容，如一个人物、一个环境、一段源视频的结构或一条音轨。每个条目单独一行，说明其标签所指内容、参考角色和需遵循的主要特征；当需要明确来源时，命名对应的源素材。如果 `<Picture N>` 或 `<Video N>` 仅标识另一参考条目的来源，且后续不会被单独分析或使用，则在该条目的定义中引用即可，无需单独成行。`retention_analysis` 记录每个参考条目的出现位置以及是完全保留、部分保留、迁移还是复用。

### 2.1 `<Subject N>`

`<Subject N>` 用于可复用的可见内容，包括：

- 人物、动物或物体
- 场景、背景或环境
- 服装、道具、界面或视觉效果
- 风格、动作、表情或姿态

它代表将在目标视频中实际使用的内容单元，而非源文件本身。一个主体可由多个参考素材定义，一个参考素材也可提供多个主体。

```text
<Subject 1> is the young woman in <Picture 1>, with long dark hair, a blue cardigan, and a thin silver necklace.
```

当同一主体来自多个素材时，合并来源并说明每个素材提供什么：

```text
<Subject 1> is the woman whose appearance comes from <Picture 1> and whose walking motion comes from <Video 1>.
```

### 2.2 `<Picture N>`

当参考图像本身用作某个镜头的首帧、关键帧、末帧、编辑后的关键帧或构图锚点时，使用独立的 `<Picture N>`：

```text
<Picture 2> is the first frame of [Shot 1], showing a woman seated beside a café window.
```

如果图像仅用于定义人物、场景、服装或风格，则不要创建独立的图像条目，而是在对应的 `<Subject N>` 定义中引用图像来源。

当图像作为分镜或镜头规划参考时，说明它映射到哪些镜头以及提供了什么规划信息：

```text
<Picture 3> is a storyboard reference for [Shot 1] and [Shot 2], defining their viewpoint, subject placement, and shot order.
```

### 2.3 `<Video N>`

`<Video N>` 专用于整段视频的关系，如：

- 编辑原始视频
- 从原始视频结尾处续接
- 参考原始视频的镜头运动、切换、节奏或时间结构

```text
<Video 1> is the source video for the target video edit.
```

如果从参考视频中复用人物、物体、场景、动作或效果作为可见内容，仍归入 `<Subject N>`。`<Video N>` 标识素材或结构来源，不替代主体标签。

### 2.4 `<Audio N>`

`<Audio N>` 代表独立的音频素材或参考视频中启用的同步音轨。常见用途包括：

- 复制全部或部分音频信号
- 参考背景音乐风格
- 参考说话者的音色和表达方式
- 使用原始音频中的对白、歌词或音效
- 参考节拍、节奏或音频连续性

当 `<Audio N>` 明确对应某个目标说话者时，在该定义中复用该说话者的全局 ID：当说话者映射到已定义的主体时写 `<Subject N> (Sx)`，否则使用稳定的嗓音描述后接 `(Sx)`。该 ID 来自目标视频的全局说话者顺序，不在音频定义中独立分配或重新编号。说话者编号规则见第 5.4 节：

```text
<Audio 1> is the voice-timbre reference for <Subject 1> (S1).
```

当一个音频素材承担多个角色时，用一句自然的语句描述这些角色，而非创建额外的子部分。

### 2.5 来自同一参考视频的画面和音轨

`<Video N>` 和 `<Audio N>` 独立编号。每个索引仅表示该标签在其自身类别中的顺序，不编码两个类别之间的配对关系。因此，同一参考视频可对应 `<Video 1>` 和 `<Audio 2>`；不同索引不妨碍它们来自同一源素材。

普通参考视频不会仅因文件包含声音就创建 `<Audio N>`。

`<Audio N>` 定义主要说明音频的角色，不一定要命名其来源的 `<Video N>`。仅在需要消除来源歧义时说明共享来源，例如：

```text
<Video 1> is the source video for the target video edit.
<Audio 2> is the synchronized audio track of <Video 1> and is reused in the target video.
```

## 3. `summary`

本部分用一小段中文概述目标视频及其参考关系。以方括号包裹的任务类型前缀开头：

```text
[reference generation] ...
[video editing + reference generation + audio reuse] ...
```

根据每个参考素材在目标视频中实际扮演的角色选择任务类型：

| 任务类型 | 使用条件 |
| --- | --- |
| `keyframe completion`（关键帧补全） | 图像用作目标视频的首帧、关键帧、末帧、编辑后的关键帧或其他具体帧锚点 |
| `reference generation`（参考生成） | 图像、视频或音频素材为人物、场景、风格、动作、镜头运动、分镜等提供生成指导，但不充当具体帧，也不作为被编辑或续接的源视频 |
| `video editing`（视频编辑） | 直接修改现有的源视频；编辑图像或在静态关键帧之间生成不属此类型 |
| `video continuation`（视频续接） | 新内容从现有的源视频延续、延伸、恢复或过渡 |
| `audio reuse`（音频复用） | 完整或部分复用同一音频信号 |
| `audio reference`（音频参考） | 不直接复制音频信号；仅参考其音乐风格、音色、对白或歌词内容、音效纹理、节拍或连续性 |

当一个任务满足多种关系时，用 ` + ` 组合任务类型，不重复同一类型。例如，从源视频续接同时使用图像作为末帧写为 `[video continuation + keyframe completion]`。编辑源视频同时保留其原始音频可写为 `[video editing + audio reuse]`。

视频或音频的存在并不自动产生对应的任务类型。如果参考视频仅提供镜头运动、切换或节奏，通常属于 `reference generation`。仅当该视频被直接编辑或续接时才使用 `video editing` 或 `video continuation`。

编辑源视频时，如果其原始音频仍可听到，同时使用 `audio reuse`。续接源视频但不直接复制音频信号时，如果新音频仅延续原始音轨的可听特征，使用 `audio reference`。

summary 使用先前定义的 `<Subject N>`、`<Picture N>`、`<Video N>` 和 `<Audio N>` 标签来描述主要主体、镜头流程和参考素材的角色。本部分不得引入新的参考标签。

对于视频编辑任务，summary 在任务类型前缀之后以以下内容开头：

```text
The target video is an edited version of <Video 1>.
```

## 4. `retention_analysis`

本部分描述每段参考内容在目标视频中如何被保留、迁移、复制或参考。每个参考标签写一行，并保持 `subject_definitions` 中确立的含义。

### 4.1 可见内容

`<Subject N>`、`<Picture N>` 和 `<Video N>` 使用以下关系标记。这些标记是输出格式中的固定英文值：

| 关系标记 | 含义 |
| --- | --- |
| `fully_preserved` | 参考内容的定义角色被完全保留 |
| `partially_preserved` | 参考内容仍被使用，但部分定义特征被改变或仅部分保留 |
| `attribute_transfer` | 参考特征被迁移到另一个可识别的目标主体 |
| `weak_reference` | 仅保留风格、类别、构图或氛围上的大致相似 |

主体条目：

```text
<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - ...
```

图像条目：

```text
<Picture 2> ([Shot 1] first frame): fully_preserved - ...
```

视频结构条目：

```text
<Video 1> (cut and pacing structure): weak_reference - ...
```

### 4.2 音频

`<Audio N>` 使用以下关系标记：

| 关系标记 | 含义 |
| --- | --- |
| `fully_copy` | 完整源音频作为目标视频的完整最终音轨 |
| `partially_copy` | 仅复制部分时间线或选定音频层，或复制后添加、移除或替换了其他声音 |
| `reference` | 不直接复制信号；仅参考音色、节奏、音乐风格、对白内容或声音纹理 |
| `weak_reference` | 仅保留类别或氛围上的大致相似 |

```text
<Audio 1>: fully_copy - <Audio 1> is reused 1:1 as the target video's complete final audio track.
```

```text
<Audio 2>: reference - the target speaker follows <Audio 2>'s voice timbre and measured delivery without copying the original signal.
```

每个关系标记仅在该标签于 `subject_definitions` 中已定义的参考角色范围内选择。不要将目标视频中新增的动作、背景或情节事件视为参考保真度的损失。

## 5. `detailed_description`

这是全参考重写的主体部分。它按目标视频播放顺序逐镜头描述画面、动作、声音和对白，并在适用处插入参考标签。

### 5.1 基本格式

基本格式遵循视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）：

- 用中文撰写主体。保留对白、歌词和可见文字的原文语言。
- `[Shot 1]` 标记开场镜头，无时间戳。后续镜头使用 `[Shot N] At MM:SS.mmm, ...` 标记切换时间。
- 将镜头运动作为当前镜头内的自然中文来写，包括需要表达时的运动类型、幅度和速度。
- 为发声源分配稳定的 `(S1)`、`(S2)` 及后续 ID。对白和歌词写为 `<d>[Language] ...</d>`。
- 对跨越切换的对白、被视频结尾截断的语音以及跨镜头的连续音频，使用 `<scenetrans>`、`<cutoff>` 和相应的连续性描述。

涵盖镜头运动词汇、多人说话、画外音、跨切换对白和可见文字的完整规则和示例，请参见视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）。

### 5.2 全参考模式差异

| 维度 | T2VA | 全参考模式 |
| --- | --- | --- |
| 主字段 | `integrated_multimodal_description` | `detailed_description` |
| 风格开场 | 写在 `[Shot 1]` 之后 | 在 `[Shot 1]` 之前用一两中文确立 |
| 参考信息 | 不使用全参考标签 | 在首次出现和角色生效处插入 `<Subject N>`、`<Picture N>`、`<Video N>` 和 `<Audio N>` |
| 音频关系 | 描述目标视频自身声音 | 在对应镜头或音频阶段引用 `<Audio N>` 并说明信号是复制还是参考 |

开场示例：

```text
The target video is in a cinematic, literary music-video style with soft lighting and a slightly desaturated color palette.
[Shot 1] The scene opens in a crowded urban street...
[Shot 2] At 00:09.000, the shot cuts to an extreme close-up...
```

对于生成任务，`detailed_description` 通常为 350–500 个中文单词。对白密集的内容优先安排完整的口语时间线，而非机械地凑字数。视频编辑类描述根据源视频复杂度灵活调整，不必遵循生成任务的字数范围。单一镜头不自动意味着更短的描述；根据各镜头的信息量在多个镜头间分配详略。

### 5.3 在镜头中使用参考标签

在重要 `<Subject N>` 首次清晰出现时，在镜头中实际可见的范围内描述其参考特征、在画面中的位置和当前动作。后续镜头中继续使用同一标签，无需重新定义标签所指内容。

具体帧锚点使用自然措辞：

```text
the shot begins from <Picture 1>
the shot's keyframe corresponds to <Picture 2>
the shot ends on <Picture 3>
```

编辑或续接原始视频时，在源状态、结构或续接关系适用处自然引用 `<Video N>`。在音频关系生效的镜头或语义阶段引用 `<Audio N>`。

### 5.4 说话者、音频源与对白

基本的说话者 ID 和 `<d>` 格式遵循 T2VA。当被参考的主体实际说话时，同时保留视觉参考标签和说话者 ID：

```text
<Subject 2> (S1) turns toward the woman and says, <d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>
```

`<Subject N>` 标识被参考的主体，`(Sx)` 标识实际说话者。主体说话时写 `<Subject N> (Sx)`。如果同一主体在画外说话，保持相同形式并标注为 `off-screen`。当说话者不对应已定义的主体时，使用稳定的嗓音描述后接 `(Sx)`。

当语音内容仅是直接复用的 BGM 或完整音轨中的提示，且没有具体人物、角色、旁白者或其他独立发声源实际产生时，使用 `<Audio N>` 作为可听来源，不另造 `(Sx)`。如果是具体人物、角色、旁白者或其他独立发声源产生的声音，则为该来源分配并复用 `(Sx)`：

```text
When <Audio 1> reaches the phrase <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d>, <Subject 1> performs the corresponding hand gesture without becoming a separate speaker source.
```

当参考音频中的对白、旁白或歌词被直接复用，或输入提示词明确要求重新演绎时，在 `<d>` 中保留精确的原文和原文语言。听不清的片段写 `[unclear]` 而非猜测或改写。标点标准化为表达句子所需的基本书面标记，如 `,`、`.`、`?` 和 `!`；移除重复的波浪号、表情符号、项目符号以及重复或装饰性标点。完整的陈述句、疑问句和感叹句分别在 `</d>` 之前以 `.`、`?` 或 `!` 结尾。

当仅参考音色、节奏、情感或表达方式时，不要将参考音频中的原始对白带入目标视频。

按照目标视频中实际发声事件的顺序一次性分配 `(Sx)`。在 `detailed_description` 中的每个实际发声事件处复用对应 ID；在 `subject_definitions` 中绑定到目标说话者的 `<Audio N>` 定义也复用同一 `(Sx)`，但从不独立分配新的 ID。不要在 `retention_analysis` 中写 `(Sx)`。仅存在于直接复用的 BGM 或完整音轨中的语音提示使用 `<Audio N>`；由具体人物、角色、旁白者或其他独立发声源实际产生的声音使用 `(Sx)`。

## 6. `overall_soundscape` 和 `non_diegetic_music`

这两个声音类别的定义遵循视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）。

`overall_soundscape` 概括整段视频的环境声和物理声音。对白、演唱和与特定镜头同步的声音事件保留在 `detailed_description` 中：

```text
overall_soundscape: Quiet indoor room tone and a low ventilation hum continue throughout the video.
```

`non_diegetic_music` 描述角色听不到、仅观众可听到的背景音乐。当存在音乐时，说明其乐器编制、速度和动态发展：

```text
non_diegetic_music: A restrained solo-piano score at a slow tempo, with sustained low cello underneath and no swell.
```

当使用参考音频时，仅在与可听层匹配的部分说明其复制或参考关系：环境声和音效属于 `overall_soundscape`，仅面向观众的配乐属于 `non_diegetic_music`。如果同一音频同时提供两类内容，在各自部分描述对应关系：

```text
overall_soundscape: The copied ambience layer from <Audio 1> continues throughout the target video.
non_diegetic_music: <Audio 2> is directly reused as the complete audience-only score.
```

完整的对白和歌词仅写在 `detailed_description` 的 `<d>` 中；不要在这两个部分中重复。

## 7. 完整示例

<details>
<summary>展示完整示例</summary>

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的咖啡店环境，包含一面裸露的砖墙、一张带有图案靠垫的橙色簇绒沙发、一个霓虹灯标志和一张木质咖啡桌。
<Subject 2> 是 <Picture 2>、<Picture 3> 和 <Picture 4> 中的蓬松白色萨摩耶犬，有着浓密的白色毛发、尖耳朵、深色鼻子和弯曲的尾巴。
<Subject 3> 是 <Video 1> 中的年轻金发女性，留着金色长发，穿着一件浅粉色卷袖纽扣衬衫。
<Subject 4> 是 <Video 2> 中的年轻男性，留着棕色短卷发，穿着一件深灰色连帽衫。
<Audio 1> 是 <Subject 3> (S1) 的音色参考，包含一个说英语的人声层。

summary:
[reference generation + audio reference] 目标视频展示了 <Subject 3> 在 <Subject 1> 中吃饼干的场景。<Subject 4> 带着 <Subject 2> 进入画面，<Subject 2> 朝饼干扑去。三镜头的交流使用 <Audio 1> 作为 <Subject 3> 的音色参考，并以罐头笑声结束。

retention_analysis:
<Subject 1> (出现在 [Shot 1]、[Shot 2]、[Shot 3] 中): fully_preserved - 裸露的砖墙、橙色簇绒沙发、图案靠垫、霓虹灯标志和木质咖啡桌均被保留。
<Subject 2> (出现在 [Shot 1]、[Shot 2] 中): fully_preserved - 萨摩耶犬的浓密白色毛发、尖耳朵、深色鼻子和弯曲尾巴均被保留。
<Subject 3> (出现在 [Shot 1]、[Shot 2]、[Shot 3] 中): fully_preserved - 金发女性的身份、金色长发和浅粉色衬衫均被保留。
<Subject 4> (出现在 [Shot 1]、[Shot 2] 中): fully_preserved - 年轻男性的棕色短卷发和深灰色连帽衫均被保留。
```
